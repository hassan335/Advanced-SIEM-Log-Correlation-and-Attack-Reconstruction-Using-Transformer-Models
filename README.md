Attack Stage Detection and Reconstruction from System Logs
Assignment Summary

This project implements a log-based attack detection and reconstruction pipeline using Transformer-based sequence models. The system classifies log events into multiple attack stages and reconstructs coherent attack chains by modeling temporal and semantic relationships between events. Two reconstruction methods are implemented: a graph-based approach and an attention-enhanced method, enabling comparison of how different modeling strategies affect event connectivity and interpretability.

The final output includes reconstructed attack chains, graphical visualizations of event relationships, and attention-based evidence highlighting influential events within each chain.

Dataset Source

The dataset consists of structured system log events labeled by attack stage. Logs were preprocessed into fixed-length sequences and tokenized representations for model training and evaluation.

Input features stored as NumPy arrays (.npy)

Separate train and test splits

Tokenized representations used for the pretrained log Transformer model

Note: Due to privacy and security considerations, the raw log data is not publicly included. Only processed feature arrays are used in this repository.

How to Run Preprocessing and Training
1️⃣ Preprocessing

Ensure the required .npy files are available in the project directory:

X_train.npy
X_test.npy
X_train_tok.npy
X_test_tok.npy


If preprocessing is required, run:

python preprocess.py


(This step converts raw logs into fixed-length sequences and tokenized inputs.)

2️⃣ Model Training

Train the baseline Transformer model:

python train_baseline.py


Train the pretrained Log Transformer model:

python train_pretrained.py


Trained models are saved for later evaluation and reconstruction.

3️⃣ Attack Reconstruction

Run the reconstruction module:

python reconstruct.py


This script applies multiple reconstruction methods (graph-based and attention-enhanced) and outputs reconstructed attack chains and visualizations.
